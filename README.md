# AXIOM Kitchen

**An interactive recipe dashboard by AXIOM VISUAL.**

[Live Demonstration](https://axiom-ui-lab.github.io/axiom-kitchen/) | [Source Repository](https://github.com/axiom-ui-lab/axiom-kitchen)

## Overview

AXIOM Kitchen is a browser-based demonstration project showcasing interactive recipe content, responsive interface design, and frontend development using native web technologies.

The public version is intended for portfolio presentation and evaluation. It should not be interpreted as a complete commercial product or a commitment to provide particular production features.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive web design

The project does not depend on a frontend framework such as React, Vue, or Angular.
